REIGN 0.1.0 PREVIEW - WINDOWS 11 X64

This package is a launch candidate. Clean-computer and native Bannerlord
acceptance must be recorded before the initial repository/package upload.

YOU NEED
Your own Steam installation of Mount & Blade II: Bannerlord v1.4.8, Microsoft
Edge (included with Windows 11), and your own account or API key for the AI
provider you choose. No developer credentials, saves or campaign database are
included. Windows 11 includes the required .NET Framework. The bundled portrait
renderer and vector worker do not require a separate .NET SDK or Python install.

INSTALL
1. Keep ReignSetup and all five Reign ZIP payloads together, then run ReignSetup.
   Alternatively, select the private download-sources.json supplied by your
   distributor. It maps client, server, runtime, dependencies and portraits to
   HTTPS download links. Do not publish or commit a file containing private links.
2. Select Bannerlord, a ReignServer program folder and a separate player-data
   folder. You can use D: or another local NTFS drive. Setup checks free space.
3. Close Bannerlord and ReignServer before installing or repairing. Setup may
   request Windows approval for Microsoft's Visual C++ runtime. If Windows needs
   to restart, restart and run setup again. Database setup runs as your user.
4. Use the Start ReignServer shortcut. Its visible server and dedicated Control
   Center start together; closing either stops the server, database and worker.
5. Configure your own provider in the Control Center. Codex users sign in with
   their own account. Provider generation can incur costs on your own account.
6. In the Bannerlord launcher enable Harmony, UIExtenderEx, ButterLib, MCM and
   Reign with their dependency order. The game module remains named ReignBeta
   internally to preserve existing module and save identities.

REPAIR AND UPDATES
Run the matching setup again with the same folders. It verifies every payload,
rejects downgrades and preserves database state, settings, backups and portraits
you edited. It retains the previous program/module directories for recovery.
Existing dependency mods with different contents must be resolved before setup
continues. Setup will not adopt an unmanaged existing ReignBeta installation.
Logs and transaction journals live in the selected data folder under setup.
A failed install retains staging evidence; correct its reported error and retry.
Close Reign before manually recovering a previous program version. Database
downgrades are not supported; preserve the current database for migration.

UNINSTALL
Use Uninstall Reign. Player data, shared/custom portraits, backups, provider
settings, dependency mods and recovery versions remain. Modified program files
also remain for recovery. Remove retained material separately only after saving
anything you want to keep.

BEFORE LAUNCH ACCEPTANCE
Test on clean Windows without WSL, Python, a developer SDK, cached models or
developer credentials. Check installation, visible startup/shutdown, game module
connection, an offline model query, a fresh campaign, save/reload, repair and
uninstall preserving player data. Offline automated proof does not substitute
for this native acceptance. Do not upload the launch candidate before it passes.
