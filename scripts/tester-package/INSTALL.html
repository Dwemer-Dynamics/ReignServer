Install Reign for beta testing

This complete tester package contains the Reign game module, its shared portraits, matching Linux server, prepared server environment, installer and player manual. Keep every file in the extracted folder together.

This is an unstable beta. Back up your native saves and matching Reign campaign history before testing. Automated build and installation checks do not certify every in-game interaction.

Before you install

  • Windows 11 on an x64 PC, virtualization enabled, and your own Steam Bannerlord v1.5.7 installation. Other game versions and storefronts are outside this package's verified scope.
  • WSL 2 installed and working. If it is missing, open Windows Terminal as administrator under your usual Windows account, run wsl --install --no-distribution, and restart Windows if requested. Then return to your normal account to install Reign. Do not use another person's administrator account.
  • Install one copy each of Harmony, ButterLib, UIExtenderEx and Mod Configuration Menu for your game version. Steam Workshop copies are supported. The installer checks their module IDs and minimum versions and preserves existing modules. Reign includes Arena Overhaul; remove its separate installation before installing this package.
  • Allow enough space for the extracted package, the game module, and at least 24 GB free on your chosen server drive. The server drive must be a fixed, uncompressed, unencrypted local NTFS drive.
  • Your own cloud AI provider account or API key is required for AI conversations. Optional new AI pictures need a separately configured image provider. Provider charges belong to your own account.

Install

  1. Get the complete tester ZIP from your distributor or locate your local copy. To verify it, compare the ZIP's SHA-256 with the separate checksum receipt.
  2. Extract the entire ZIP to a short local path such as C:\ReignPackage. Open the extracted Reign folder. Do not run the installer inside the ZIP viewer.
  3. Close Bannerlord and its launcher. Open Install.cmd. Enter the full path to your Steam Bannerlord folder when asked. The default server location is %USERPROFILE%\ReignTester. The complete hash check can take several minutes for large images and portraits.
  4. If you prefer another server drive, open Windows PowerShell in this folder and run:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Reign.ps1 -BannerlordRoot "D:\SteamLibrary\steamapps\common\Mount & Blade II Bannerlord" -InstallRoot "D:\ReignTester"

The installer creates its own ReignServer WSL environment and a fresh local player database. It does not replace an unrelated distro, adopt a previous developer/legacy installation, move your dependency modules, or launch Bannerlord. An existing unrelated installation causes a refusal so it can be reviewed safely.

First launch

  1. Open Start Reign Tester on the Desktop. Wait for the server and memory worker to finish starting. The first model load may take time.
  2. Use the Control Center at http://127.0.0.1:8089/ to configure your own dialogue provider and optional image provider. Confirm the server is healthy. The Control Center manages server start and stop.
  3. Enable ReignBeta and its required dependencies in the Bannerlord launcher. Start Bannerlord yourself. Let campaign preparation finish before interacting.
  4. Read the included Reign User Guide for controls and play. It is the latest available illustrated manual; its source-reviewed edition is November 9, 2026. This installation page describes the current tester installer. New beta behavior may be newer than that manual.

Updates and interrupted installs

For a newer tester package, close the game and use the same game/server folders with -Update. Only a previously owned tester installation can be updated. Its database, settings, campaigns and previous runtime are retained. Changed or unknown module files cause a refusal.

If installation stops, keep its extracted package, server folder and transaction journal under ReignTester\transactions. Fix the reported problem, then retry the same command with -Resume. Never delete a distro or player-data folder just to clear an error. Some interrupted storage/import or conflicting backup states require inspection before retrying.

-VerifyOnly checks package integrity and installation prerequisites without installing. It does not prove a complete clean-computer install or native gameplay.

What the package keeps private

No distributor API keys, personal settings, campaigns, saves, campaign portraits or player database are supplied. Each tester provides their own game, dependency mods, provider credentials and campaign. The server environment includes the fixed dependency/model versions identified in its receipt.

For a beta report, include your package ID, game version, steps to reproduce and a screenshot of the error. Review logs before sharing them; they may contain your conversations. Do not share API keys or your entire player database publicly.
