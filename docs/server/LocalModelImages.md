# Local Model image profiles

The **AI Image Generation** tab offers **Local Model** independently for Normal Portraits, Adult Portraits, Normal Scenery & Events and Adult Scenery & Events. Local Model uses **qwen-image-2.1-int8**. In Local Model Desk, turn Qwen on before requesting an image. The Desk needs to run on the ReignServer WSL loopback. Its Windows control center can also open the shared loopback at port 18500. Reign requires no image API key for this provider.

The generation URL defaults to http://127.0.0.1:18500/v1/images/generations. The edits URL defaults to http://127.0.0.1:18500/v1/images/edits. Each address needs the matching HTTP loopback route. Image requests use JSON and accept the Desk's PNG response in `data[0].b64_json`. With a reference, Reign sends the reference bytes as an image data URL to the edits route. A Local Model normal portrait passes its native image directly to Qwen. Cloud portrait profiles retain their separate vision conversion.

Each profile saves its own canvas, steps, guidance, sampler, scheduler, negative prompt, reference resolution, fit-to-reference switch and optional random seed. Canvas dimensions must be multiples of 32 between 256 and 2048. The portrait product still requires a portrait-oriented image of at least 768x1024 and applies its existing composition and face checks. View retains a 3:2 canvas at 1536x1024 or larger. Fixed-canvas requests override fit-to-reference. Fitted edits can return larger or smaller dimensions than a fixed canvas. A fitted response must have 32-aligned sides from 32 to 4096 pixels and at most 4,456,448 pixels total. Reduce reference resolution if native or unusually shaped references exceed these bounds. Guidance must be 0.1–20, steps 1–100, and reference resolution either 0 for native or a supported canvas dimension. Leave the seed blank for a fresh seed.

If a former NanoGPT profile used the exact Local Model Desk route at loopback port 18500, first load migrates only that profile to Local Model and restores the corresponding NanoGPT URL default. The NanoGPT image and text credentials, other providers and genuine NanoGPT addresses are preserved. Verify all four selections after upgrading. NanoGPT image credentials only go to genuine NanoGPT HTTPS destinations. A Local Model request never resolves, sends or redirects those credentials.
