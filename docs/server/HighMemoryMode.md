# Retired remote memory modes

2026-10-01: High Memory Mode, the pre-writing evidence analyst, finished-reply checker and semantic memory rewrite have been removed from settings and the runtime. The unused LLM context selector, its prompt/default and retired Minime UI placeholders are removed too; local helpers still used by background queries retain their configuration. This path is retained for historical documentation links.

Current retrieval uses the local memory pipeline described in [MemoryPrecision.md](MemoryPrecision.md) and [SpecialistMemory.md](SpecialistMemory.md). The ordinary Memory model still creates summaries; dialogue, correspondence and relationship model selections remain separate. Source eligibility, chronology, observer privacy, question/answer links and final prompt preflight remain active. Format recovery and action validation retain their existing authority.

On settings normalization, retired flat options and provider model-bank entries are removed idempotently without changing active models or credentials. Legacy enabled flags cannot dispatch a helper; retired request purposes reject before provider use. The isolated local evidence replay accepts only disabled legacy flags and retains actual writer and next-read testing. Historical dialogues, diagnostics and verification data remain unchanged.

Cleanup does not activate unqualified local helpers or imply native/semantic acceptance. See the paired dialogue testing procedure for exact artifact validation and provider-free web preview requirements.
