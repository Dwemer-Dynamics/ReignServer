# Initial v5 roster authorship

This directory preserves the task-authored material for the initial 1,117-character
roster. The 664 hobby details and 2,096 concern meanings were written in the Codex
task, then composed locally using the preserved identities and personalities.
These are not 1,117 independently handwritten biographies and were not generated
through the construction provider. Shared interests and family facts are expected;
each life account and defining-interest trio is distinct.

`assemble_draft.py` uses no network or provider. It reads the immutable v4 catalog,
the canonical concept and compatibility libraries, and these authored tables.
It writes review drafts only beneath `.codex-build/background-rebuild-20260909/`.
It never edits installed files, saves, or the shipping catalog. Source order hashes
protect the indexed prose mappings. Runtime scale and guard text are copied from
their canonical C# declarations.

Review combines full data checks with focused editorial inspection of children,
adolescents, rulers, deceased characters, low-compassion personalities, and the
closest biography pairs. This is not a claim that every sentence received a separate
individual review. Personality eligibility uses the original trait percentages,
foundation traits and Court honor; native kin evidence limits family-specific
memories. Low compassion cannot receive a care-driven philanthropic dream.

Final runtime `ready` status means a complete content candidate. Deployment still
requires successful manifest-selected validation, full roster contracts, bounded
dialogue behavior evaluation, and the user's deployment authorization. Offline
checks do not establish native campaign save/load acceptance.
